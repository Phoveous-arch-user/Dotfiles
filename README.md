# dotfiles

Personal Hyprland desktop configuration backup.

## Contents

| What | Where |
|---|---|
| Hyprland config (lua) + scripts | `.config/hypr/` |
| Waybar | `.config/waybar/` |
| Rofi (launcher + theme/wallpaper pickers) | `.config/rofi/` |
| Kitty | `.config/kitty/` |
| Theme color files | `.config/ml4w/` |
| SwayNC (notification center) | `.config/swaync/` |
| matugen templates (theme color engine) | `matugen/` |
| Theme wallpapers | `Pictures/Themes/` |
| SDDM (lock screen) | `sddm/` |

## Themes & wallpapers

Every theme is a folder in `~/.config/hypr/themes/<Name>/theme.conf` describing
its wallpaper(s), color scheme and accent.

| Action | Keybind |
|---|---|
| Theme picker (rofi grid) | `CTRL + Tab` |
| Wallpaper picker (strip of the active theme's wallpapers) | `SUPER + W` |
| Previous / next wallpaper | `CTRL + left` / `CTRL + right` |

Scripts:

- `~/.config/hypr/scripts/theme-switcher.sh` — apply a theme (wallpaper + matugen colors + reloads)
- `~/.config/hypr/scripts/wallpaper-picker.sh` — horizontal wallpaper strip for the active theme
- `~/.config/hypr/scripts/wallpaper.sh` — `set`, `select`, `next`, `prev`, `random`

Bundled themes: Catppuccin Mocha, Iceland, Mclaren, Minions, Rose Pine,
Spider-Man, Decay Green, Undertale, Winter, Tokyo Night.

To add a theme: create `~/.config/hypr/themes/<Name>/theme.conf` (see an existing
one) and drop its wallpapers in `~/Pictures/Themes/<Name>/`. It is picked up
automatically.

## Install / restore

```bash
./install.sh          # symlink configs back into ~/.config, needs sudo for SDDM
./install.sh --force  # replace existing configs (old ones kept as *.bak)
```

## Re-backing up SDDM (run after changing the lock screen)

```bash
sudo cp -a /usr/share/sddm/themes/pixel-night-city sddm/theme-pixel-night-city
cp /etc/sddm.conf sddm/sddm.conf
```

## Backing up user configs

`install.sh` symlinks the tracked `~/.config` dirs (hypr, waybar, rofi, kitty,
ml4w, swaync) into this repo, so on a fresh restore edits are saved here
automatically.

If the dirs already existed when you ran `install.sh`, they were left as plain
**copies** (use `./install.sh --force` to convert them to symlinks). In that case
copy your edits in manually, then commit:

```bash
git add -A && git commit -m "update configs" && git push
```

> Note: the color files under `.config/{waybar,swaync,rofi,ml4w,kitty}` are
> regenerated by matugen on every theme switch, so they change often.
